# 《东海壁垒》制作规范（Skill）

## 一、世界观硬设定（不可更改，需反复核对）

1. **地名**：湖名 = 东湖，全名「上海东湖」（原滴水湖）。堡垒名 = 东海壁垒。
2. **地理**：三面环海，是天然防线。
3. **城墙**：湖心不算一圈，外面共 **三圈** 环形城市/城墙，每圈千米级高度，墙顶刺入低云；三圈之间以悬空通道、磁悬浮轨道、地下隧道连通。
4. **空间站**：巨型环状，直径 3 公里以上，有环形居住环、中央主轴、多组对接臂。
5. **反重力升降机**：三圈城墙每圈各 3 条，共 **9 条** 白金色光柱通道，从各圈城墙直插空间站。
6. **护盾**：一个巨型能量罩，从地下建筑一直包到**空间站顶部之上**，空间站与地面城市全在罩内。
7. **母舰**：敌舰，**永远在护盾之外**，不得压在护盾正上方，也不得进入罩内。
8. **液相体本体**：黑色流体，无固定形态；智商极高，自动学会人类语言、可模拟人形；**脆弱如人，一击即死，无战斗力**；**怕水，落水即溺**。因此永不亲临，只藏在密封舱内操控机器。
9. **液相体机器**：**不怕水**，可下水、可潜水；能夺控人类联网机械。
10. **人类武器**：可变形激光炮（炮 ↔ 手），可击穿机器外壳、直接击杀舱内本体；水是第二重保险。
11. **机甲**：原版设计（修长人形、背部翼状荚舱、肩部圆形护盾发生器、肩载导弹、能量刃），配色 **暗红 + 鎏金 + 白金能量光**，**禁用蓝白**。
12. **防守逻辑**：护盾**极难破**——必须多点集中火力**持续输出很久**，累积过载才撕开**单扇区**的小口子；城墙**绝不会全面崩塌**，只破口下方那一段殉爆；其余城墙完好、轨道炮继续还击。

## 二、图片生成规范

- **尺度必须用参照物**：以 25 米高的机甲作参照，机甲只占墙高不到 1/30；人形士兵细如蚂蚁；墙顶插入云层。只写"几百米/几千米"无效。
- **角度冲突原则**：
  - 俯瞰/中高空 → 能拍清三圈城墙层次，但空间站会变小
  - 仰视 → 空间站和穹顶能做巨大，但三圈层次会糊
  - **一张图不要强求同时满足，按镜头分工分别出图**
- **限制**：单张图只解决一个重点，提示词不要堆太多目标。

## 三、视频生成规范（重点，之前失误的地方）

### 硬性规则
1. **镜头数**：15 秒最多 **2-3 个镜头**；每镜 5-7 秒，单镜一条连续动作。**严禁 15 秒塞 5 个镜头。**
2. **写动作，不写画面**：必须写清镜头怎么动（推进/跟拍/手持/甩镜）、物体怎么动、速度、物理反馈。
3. **参考图 ≤ 2 张**：参考图过多会把模型钉成"复刻静帧"，导致画面呆滞。
4. **分辨率 720p**：480p 会糊掉运动细节，显得像幻灯片。
5. **物理与军事逻辑必须写具体**：
   - 护盾：写"多台机器 + 母舰主炮同时轰击同一扇区、每秒叠加、能量由青蓝转红、明暗闪烁、涟漪越来越大、累积到极限才裂开小口"；
   - **禁止**出现"一炮就破""整片崩塌"；
   - 战斗：写"敌军高速冲入、被交叉火力拦截、爆裂、黑液迸溅、碎片飞散、机甲后座退步、冲击波震开雨幕"；
   - **禁止**敌人"像路人一样走过去"、无对抗、无冲击的画面。
6. **不得擅自生成**：每次生成前，先把提示词/方案给用户确认，得到同意再调用工具。

### 常见"呆"的成因（自查表）
| 症状 | 成因 |
|------|------|
| 画面不动 / 像幻灯片 | 镜头太多、每镜太短 |
| 动作僵硬 | 提示词是静态画面描述 |
| 复刻静帧 | 参考图给太多 |
| 糊、没动感 | 分辨率太低 |
| 不合常理 | 没写清过程与物理反馈 |
