# 第一集《黑色来客》角色一致性包

- 版本：v1（2026-11-02）
- 用途：图生视频/图生图时锁定人物长相、发型、制服与空间关系
- 关键帧目录：`/workspace/donghai-bibao/keyframes/ep01/clean/`
- 制服对照总图：`/workspace/donghai-bibao/keyframes/ep01/ep01_character_sheet_v3.jpg`

## 锁定原则

1. **一张脸只有一个主锁**。近景用主锁，全身/群像只验证制服与发型，不让模型从群像里重新学脸。
2. **先锁人，再锁场**。人物镜头最多传 2 张人物图，第 3 张才给环境；环境图里若有人物，必须先说明「只取背景」。
3. **发现冲突图就停用**。本包第 5 节列出三张已知冲突图，不得再作为人物参考。
4. 生成后按第 7 节检查表逐项打勾，任一项不符即判失败。

- 主舷窗：画面右后或正后，取决于机位；S07/S11 朝窗拍。

## 7. 黑球比例与可见度

| 场景 | 画面尺寸 | 规则 |
|---|---|---|
| 望远镜屏幕（S01） | 可占屏幕 1/3–1/2 | 纯黑，无表面细节，无边缘光，只遮星 |
| 发射井准星（S04） | ≤ 8px @480p | 针尖黑点，不得放大 |
| 导引头（S05） | ≤ 8px @480p | 针尖黑点，不得出现球面 |
| 舷窗（S07） | 大黑盘，可遮住半个窗 | 仍无边缘光；星群被挖空一块 |
| 命中（S08） | 大黑盘 | 裂纹发光，无烟柱、无火球 |
| 登陆舱（S11） | 小点/小方块 | 暗色舱体+白色航灯+细红轨迹，不得画成巨型飞船 |

**绝对禁止**：把黑球画成有大气层的行星、有金属反光的球体、有边缘光的剪影、有吸积盘的黑洞。
