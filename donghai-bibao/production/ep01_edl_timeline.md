## 视频处理顺序

1. **离线剪辑**：全部镜头用 480p 代理，统一 24fps、1080×1920 时间线，先确认节奏与转场。
2. **去水印**：所有 AI 生成片先处理水印，再进在线时间线。已知参数：496×864 输出用 `crop=460:820:18:0`；其他尺寸按右下角等比裁切，再放大到 1080×1920。
3. **统一画幅**：源片非 9:16 时，先等比放大到高 1920，再居中裁宽到 1080；不允许拉伸变形。
4. **在线替换**：通过的镜头用 720p/1080p 版本替换代理，时间码不变。
5. **特效叠加**：
   - S01 警报逐层亮起：红色扫光/亮度动画，不重新生成。
   - S03 发射序列：本地 UI 叠在屏幕上，不依赖 AI 文字。
   - S08 闪白、滤光板、碎片补层：本地合成。
   - S12 上海锁定框、轨迹线：本地 UI 叠加强化。
6. **调色**：统一冷蓝底，保留红/绿状态色；黑球区域不得提亮，确保纯黑。

## 剪辑顺序建议

不要从 S01 开始剪。按以下顺序，先锁节奏骨架，再补细节：

1. 先接 S04 → S05 → S06（发射段，验证方向与节奏）。
2. 再接 S07 → S08 → S09（合围、命中、假胜利，验证闪白）。
3. 再接 S11 → S12 → S13（二次目标到地面，验证钩子）。
4. 最后接 S01 → S02 → S03（开场与授权，验证长镜）。
5. 全片过一遍，只看「有没有想快进」；有就缩短对应镜头，不加转场救。
