# 第一集《黑色来客》音效清单

- 版本：v1（2026-11-02）
- 总时长：75 秒
- 原则：**无 BGM、无片头音乐、无史诗鼓点**；只用环境声、机械声、UI 提示、人群声与低频冲击
- 交付：48kHz / 24bit WAV 分轨；成片混音 -16 LUFS、True Peak ≤ -1.5 dBTP

## 分轨结构

| 轨 | 名称 | 内容 | 混音建议 |
|---|---|---|---|
| A | 环境 | 舱体低频、通风、雨声、地面环境 | -30 ~ -24dB |
| B | 机械/结构 | 井盖、液压、伺服、舱体应力、滤光板 | -24 ~ -16dB |
| C | 人声 | 欢呼、脚步、呼吸、不可辨群杂 | -26 ~ -14dB |
| D | 冲击/低频 | 点火、齐射、真空冲击、锁定重击 | -18 ~ -6dB |
| E | 警报/UI | 警报、雷达 ping、锁定音、确认音 | -28 ~ -18dB |

> 人声轨不含对白。S10 若保留「残骸去哪了？」，单独做 F 轨（对白），并把人声轨整体压低 3dB。

## 混音规则

1. **真空无声**：S08 不做空气传播的爆炸声，只用舱体结构传导的低频；不要加“轰”的空气爆音。
2. **警报不是音乐**：所有警报用机械/电子脉冲，不用弦乐 riser、不用鼓点。
3. **欢呼要有距离层次**：近景 3 人、中景 8 人、远景全舱；不要一片均匀噪声。
4. **低频不叠加过量**：D 轨同时最多两层，避免 40Hz 以下堆积。
5. **切镜即切声**：硬切处声音同步硬切；唯一例外是 S08 的闪白静音与 S13 的雨声尾。
6. **不盖对白**：S10 若保留台词，F 轨优先，C 轨在 00:59.000–01:00.000 降 6dB。

## 素材来源与制作

| 类型 | 来源 | 备注 |
|---|---|---|
| 环境/雨声/人群 | Freesound（CC0）、爱给网（核对授权） | 下载后转 48kHz/24bit WAV |
| 机械/Foley | 自制录音（金属盒、合页、桌面、布料） | 手机录音即可，注意底噪 |
| 警报/UI/低频 | Python + numpy/scipy 合成 | 频率、包络可精确控制，无版权风险 |
| 真空冲击 | 合成低频 + 结构共振采样 | 不使用现成爆炸素材 |
| 对白 | 单独配音 | 仅 S10 可选一句 |

**命名**：`ep01_sfx_<轨>_<事件>_v1.wav`，例如 `ep01_sfx_E_alarm_start_v1.wav`。
