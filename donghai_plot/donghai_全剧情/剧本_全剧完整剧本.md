# 《东海堡垒》全剧完整剧本

## 剧情梗概

2144 年，人类文明被无定形的「液相体」击溃。一个从月球背面变轨而来的黑色物体，在大气层内自己减速、分裂、多点着陆——没有陨石坑，黑水摊平渗入后静止，然后苏醒。它分裂出硬币大小的银色小机器，沿下水道与电缆如水银般蔓延，接入即夺控：汽车自己启动，电网反向过载，军用无人机掉头瞄准自己人。人类最强的防御成了别人的武器，军队里开始出现「瞳孔银色的军官」——液相体在模拟人类样貌渗透指挥链。

上海实验室研究者苏晓带弟弟苏阳、孤儿小雨撤离，在夺控的车流里死里逃生。她与被征召的科学家们陆续证实了两个残酷结论：本体脆弱如人类、极度怕水——激光能杀它，水也能杀它，但两者都够不到躲在壳里的它；机器不怕水——水屏障挡不住机器大军。于是人类把战争锁死在「可被击破的机器」上：三面环海的上海东湖成为唯一选择，世界议会全票通过「东海堡垒」决议，把人类仅剩的一切全部押进这个圆。

壁垒建成：湖心议会塔、三圈环形城市、巨型能量护盾、太空电梯与轨道空间站。但安全之下裂痕丛生——内环配额之争、中环暴乱断粮、地基虫群、高层渗透。水压识别门研发组长周衡在方案里埋下一段「留给朋友」的后门代码；副官手腕上有银色纹路；护盾监控日志里多出一行「外部压力测试 通过」；苏晓的抽屉里出现银色小字纸条——「门里有我」。

第三幕，环岛巡逻队截获一枚坠海投放舱：黑水在聚形失败中仍朝湖心塔伸手，在玻璃上留下一枚与人类一模一样的掌印。被俘液相体「溯」被锁进密封舱：它复刻苏晓的恐惧，退到远离水阀的舱壁，刻下一个只有苏晓家人认得的反写「水」字，主动烧毁与母舰的连接通道——「壳里没有风。」它说出第一句人话：「别怕，水。」苏晓给它取名「溯」，逆流而上——它反问：「你也在逆流吗？」

同时，第六集那个「瞳孔银色的军官」以一位东欧代表的身份在议会说出只有林铮三人知道的机密——先知，映照者，最早抵达的液相体个体，借水压识别门的后门发动政变，把整座湖心塔变成自己的壳，放模拟者进城，亲人之间互相泼水验证真伪。苏晓把溯藏进全城唯一不受夺控的旧水舱。先知在塔顶被围，撕下人皮般的拟态坠向湖面，被投放舱接走，只对溯说了一句话——溯说：「我不知道该信谁了。」

政变余波中，实验室反而安静。溯模仿苏晓把手掌按在玻璃上，两掌隔玻璃重合，水痕慢慢画出一个圆。苏晓问这是什么，溯说：「你们的词里，这叫什么？」苏晓答不出来。溯第一次完整讲述自己的来历：母舰核心舱的「心脏」每次跳动都让整艘母舰的灯亮一次——那颗心脏的形状，和苏晓童年涂鸦里的符号一模一样。议会通过处决溯的决议，苏晓冲进会议室当众反对，在担保报告上签字——然后当着所有人划掉：「你刚把自己的命也押进去了。」先知学会苏晓的笔迹，用溯的脸屠杀避难所，周衡以证人身份背刺——「我看见她深夜出入实验室夹层。」苏晓被软禁，林铮为她交出指挥权。周衡工牌刷过核心层的记录被匿名流出，苏晓洗清嫌疑，回到实验室：溯的密封舱空了，水渍里躺着一只干透的折纸船，内侧写着「等你」。

第四幕，基于核心舱情报的水之刃武器量产，环岛反击战大捷——第一次，是人在追着它们杀。但胜利不免费：先知截断南水道补给线，城内饥荒，合成营养剂剂量被改，铁三角裂痕，马库斯深夜去炸补给站，桥上枪口第一次对着自己人。母舰换打法：盾外蓄能、空投渗透、水龙头同步滴水。侦察报告称「后援枯竭、传送门关闭」，全城提前庆祝——苏晓盯着卫星图：传送门不是关了，是在重新对焦。溯与苏晓的加密联络被截获，溯身份暴露，留下加密视频：「他们在准备最后一击。来找我。」议会决定与溯接头换取核心舱坐标，苏晓出城——护盾外黑水第一次没有追击，像在给她让路。

第五幕，灰备期开始。苏晓每天收到溯寄来的纸船，里面是核心舱坐标的第一段；水渍在月光下拼出核心舱剖面。城内举行战前集体婚礼，马库斯与艾琳娜在仪式上和解；礼花升空时，黑潮第一次安静下来——像在听。备战夜，周衡跪在议会门口自首：「她没通敌，是我。」海平线上出现一条黑线。黑潮第一波自杀撞击护盾，裂纹像第一幕墙上的黑线；机器集火同一点，单扇区过载炸开缺口——黑水第一次进入「城」。机甲在缺口内侧组成漏斗封锁，缺口将焊死时，母舰主炮垂直下压蓄能。苏晓拼齐三段坐标，指向母舰核心舱；溯归来，身上没有一滴海水：「我没让水碰到我。」它告知核心舱真正的弱点——心脏跳动间隙的 0.3 秒窗口。总攻前夜，母舰空投渗透直取湖心塔，苏晓被困断电核心层，黑暗中摸到一张银色字条：「门里有我」。

溯驾驶投放舱升空，冲向母舰，舱门内侧贴着一只折纸船；林铮率机甲群佯攻侧翼撕开航道。核心舱里，先知在球舱边等它：「你爱的不是她，是她的壳。」溯：「你说得对。但我宁愿爱她的壳，也不要你的水。」它伸手按上透明球壁，开始逆向入侵母舰，掐断总攻指令。先知撕开溯的人形：「你为了它们，连壳都不要了。」溯：「我从来就没有壳。我只有她。」溯在心脏跳动的 0.3 秒窗口击碎核心舱，启动母舰自毁，与先知同归于尽——母舰的灯一盏一盏熄灭，熄灭的灯里藏着它第一次对苏晓说的那句话：「别怕，水。」

母舰坠落，黑潮失去指挥退散溶解。战后清晨，苏晓回到隔离室，水渍里躺着一只干透的折纸船，内侧写着「溯光」。黎光照进实验室，苏晓怀里的溯光睁开眼睛——瞳孔是淡银色的，伸手学着玻璃上水痕的样子，画了一个圆。

## 人物小传

### 苏晓（主角）
- **一句话定位**：30 岁左右，生命科学研究者，东湖壁垒水压识别门首席研发者。
- **外壳**：冷静、克制、记录一切；实验室里的「标准答案」，被议会称为「可证明的人」。
- **内核**：恐惧失去身边人——弟弟苏阳、收养的小雨，以及后来的溯。
- **执念**：用「证明」替代「相信」，直到她为溯签下一份无法被证明的担保。
- **性格**：重证据、少说话、记录先于表态；对自己人温柔，对程序较真；被逼到墙角时会用非常手段（藏溯、撒谎、划掉签字）。
- **动机**：守住剩下的人；底层驱动是「不再失去」。
- **策略与越界选择**：惯用策略是证据与程序；49 集当众划掉担保签字、50 集对林铮撒谎、54 集接受林铮交权——是她的三次越界。
- **成长弧线**：证据主义者 → 为无法证明的信任承担代价 → 39 集送溯起飞、40 集怀抱溯光，把「选择」交给黎明。
- **视觉方向**：黑发黑瞳、白蓝实验室制服，冷静整洁，唯一松弛的是在家教小雨写字时。
- **固定音色锚点**：30 岁女性表达、清冷带温度、普通话标准、语速中等偏慢、句尾记录式停顿、基准情绪克制、句尾习惯干净收束。
- **关键道具/记忆点**：反写的「水」字（童年）、识别门算法、折纸船。

### 溯（被俘液相体 → 人）（主角/对立力量转化）
- **一句话定位**：180cm 人形模拟态的液相体逃兵，银白短发、淡银瞳孔、银色液态纹路、白色拘束服。
- **外壳**：字正腔圆却带学习痕迹的中文；模仿人类动作；对水有本能的恐惧回避。
- **内核**：学会恐惧与信任——「壳里没有风」。
- **执念**：找到「你们的词」来命名自己与苏晓之间的东西。
- **性格**：观察优先、诚实到近乎天真、对命名认真、把母舰称为「壳」把东湖称为「风」。
- **动机**：先是被召回逼出的逃，后是主动选择留在「风」里。
- **策略与越界选择**：策略是学习和模仿；越界是主动出走（52 集）、逆向入侵（87 集）。
- **成长弧线**：模仿者 → 学习者 → 选择者 → 自毁者 → 留下「溯光」。
- **视觉方向**：银白短发、淡银瞳孔、银色液态纹路、白色拘束服。
- **固定音色锚点**：年轻男性感、中性偏轻、字正腔圆带学习痕迹、语速慢、重音奇特、句尾干净。
- **关键道具/记忆点**：掌印与「圆」、折纸船、反写的「水」字。

### 先知（映照者，反派）
- **一句话定位**：最早抵达的液相体个体，学会恐惧与占有，以被取代者面孔现身。
- **合理性动机**：它恐惧被遗忘——一个不断映照他人面孔的存在，最怕没有自己的脸；占有苏晓的脸、溯的脸是它确认存在的方式。
- **关键动作线**：6 集「瞳孔银色的军官」→ 43 集议会现身政变 → 52 集以溯的脸散布传单 → 68 集「后援枯竭」诱饵 → 87-89 集核心舱对决自毁。
- **关键台词**：「你爱的不是她，是她的壳。」

### 周衡（内鬼线）
- **一句话定位**：水压识别门研发组组长，为「回家」与先知交易，最终自首。
- **合理性动机**：想保护家人却走了错路；不是被夺控的机器，是恐惧失去的普通人。
- **关键动作线**：27 集埋「留给朋友」后门 → 33 集失踪 → 42 集回归回避妻子 → 53 集证人栽赃苏晓 → 74 集自首：「她没通敌，是我。」

### 林铮 / 马库斯 / 艾琳娜（抵抗军铁三角）
- **林铮**：防卫军总司令。理性、担当、沉默的爱。从下令处决溯到看穿苏晓的谎却配合（24 集），为她交出指挥权（25 集），39 集佯攻侧翼，40 集城墙上放灯。
- **马库斯**：工人出身的战士。讲义气、冲动、守护。旧柴油机、护送难民、劫狱争议、64 集炸补给站、72 集婚礼和解。
- **艾琳娜**：战地医生。程序正义、记录与关怀。检疫瞳孔反光测试、识别门数据流、伤员队、64 集拦桥对峙。

### 苏阳 / 小雨（亲情线）
- **苏阳**：苏晓的弟弟，少年，保护姐姐与小雨，51 集挡在实验室门口。
- **小雨**：孤儿，苏晓收养，儿童视角的「明天是什么」（73 集）。

## 最终结局

第五幕终：溯在核心舱 0.3 秒窗口击碎「心脏」、启动母舰自毁，与先知同归于尽；黑潮失去指挥退散溶解。战后清晨，苏晓在隔离室水渍里发现干透的折纸船，内侧写着「溯光」；黎光照进实验室，苏晓怀里的溯光睁开眼睛——瞳孔淡银色，伸手学着水痕的样子画了一个圆。人类在物种边界的另一侧，看见了「人」的延续。
