# 《东海堡垒》全局设定与分集总纲

# 全局故事圣经

## 1. 世界观与故事规则

**时间与背景**：2144 年，人类文明被无定形的「液相体」击溃。2144.3 起，黑水从月球背面变轨坠落，全球多点着陆、机器夺控、各国沦陷；2145 年起人类三面环海的上海东湖建起「东海堡垒」，作为最后的防线。故事跨度 2144.3 – 2147.3，共 40 集（2026-10-30 压缩重排，原 90 集规划见备份文件）。

**液相体 · 本体**：无固定形态的黑色流体，可随意变幻身形；智商极高，无需教学自动学会人类语言、模拟人类样貌，是天生的谋略者。物理层面与人类一样脆弱——普通刀枪、激光一击即死，没有超自然防御力与战斗力，因此它从不亲临战场，永远密封在载具舱内、靠操控机器作战。极度怕水：对它而言水等同深渊，落水即溺。

**液相体 · 机器**：分裂出的银色小机器（硬币大小，接入即夺控）与巨型战争机器。不怕水，可潜水、可穿越水域。真正的死穴是「壳被打破」。

**战斗公式（已修正）**：人类 = 机甲/武器（可变形激光炮等）击穿舱体 → 光束直接贯穿击杀内部本体；水为双重保险——本体脆弱如人，落水即溺。机器只是壳。东湖的价值是让本体永远不敢亲自把壳开到你面前：三面环海，它的载具一旦穿越大海就随时可能被击沉。

**东海堡垒 · 结构**：湖心议会塔 + 太空电梯基座；向外三圈环形城市带（内环居住、中环工业军事、外环防御）；外圈多组垂直通道直连轨道空间站；整座城市被巨型能量防御罩包裹。护盾之外是工业坟场：液相体建造的巨大黑色汲取管道掠夺地球物资。

**液相体 · 母舰**：黑曜石液滴形巨型舰体，无接缝一体化，表面为缓慢流动的黑色液态金属，内部透出银白光点如星群，尾部伸出触须状稳定鳍。舰体最深处是密封核心舱——发光的黑色本体悬浮在耐压透明球舱内（溯称其为「心脏」），多重耐压外壳包裹，与海水完全隔绝。怕水的只是本体，母舰舰体本身属于机器、不怕水。核心舱既是指挥中枢，也是移动要塞。母舰通过海底基地的环形传送门成批抵达。

**核心软肋（第五幕揭示）**：核心舱「心脏」的跳动存在 0.3 秒间隙窗口，需从内部击碎——这是溯逆向入侵母舰的价值所在。

**关键矛盾**：人类集体求生 vs 议会配额与阶级裂痕；内鬼（周衡、先知渗透）vs 信任；溯（逃兵→人）vs 先知（占有者）；爱与物种边界。

## 2. 主要人物与关系

### 苏晓（主角）
- 一句话定位：30 岁左右、生命科学研究者、东湖壁垒水压识别门首席研发者。
- 外壳：冷静、克制、记录一切；实验室里的「标准答案」。
- 内核：恐惧失去身边人（弟弟苏阳、孤儿小雨、以及后来的溯）。
- 执念：用「证明」替代「相信」——直到她为溯签下人生第一份无法被证明的担保。
- 成长弧线：从证据主义者 → 愿意为无法证明的信任承担代价 → 在终战中把「选择」交给溯与黎明。
- 关键道具：反写的「水」字（童年记忆）、水压识别门、折纸船。
- 音色锚点：30 岁女性，清冷但带温度，普通话标准，语速中等偏慢，句尾常带记录式停顿。

### 溯（被俘液相体，后为「人」）
- 一句话定位：最早「逃兵」化的液相体，从模仿者成长为选择者。
- 外壳：银白短发、淡银瞳孔、银色液态纹路、白色拘束服的人形模拟态（180cm）。
- 内核：学会恐惧与信任——「壳里没有风」，它把母舰称为「壳」，把东湖称为「风」。
- 执念：找到「你们的词」来命名自己与苏晓之间的东西。
- 成长弧线：模仿恐惧 → 开口说人话 → 取名溯 → 信任苏晓 → 主动出走带母舰弱点 → 逆向入侵自毁。
- 关键道具：玻璃上的掌印与「圆」、折纸船、反写的「水」字、母舰核心舱「心脏」。
- 音色锚点：年轻男性感，中性偏轻，字正腔圆的中文（带学习痕迹），语速慢，重音奇特，句尾干净。

### 先知（映照者，反派个体）
- 一句话定位：最早抵达的液相体个体，学会恐惧与占有，以被取代者面孔现身。
- 合理性动机：它恐惧「被遗忘」——一个不断映照他人面孔的存在，最怕没有自己的脸。它通过占有苏晓的脸、溯的脸来确认自己的存在。
- 关键动作线（压缩后集号）：第 3 集「瞳孔银色的军官」→ 20-21 集借水压识别门政变 → 24 集以溯的脸散布传单 → 32 集「后援枯竭」诱饵 → 第五幕与溯在核心舱对决（39 集）。
- 关键台词候选：「你爱的不是她，是她的壳。」（39 集）

### 周衡（内鬼线）
- 一句话定位：水压识别门研发组组长，为「回家」与先知交易，最终自首。
- 关键动作线（压缩后集号）：12 集在识别门方案埋「留给朋友」后门 → 15 集失踪 → 20 集「回归」且回避妻子提问 → 25 集以证人身份栽赃苏晓 → 34 集跪在议会门口自首：「她没通敌，是我。」
- 内核：不是被夺控的机器，是一个「想保护家人却走了错路」的人——这是内鬼线的灰度和证据链基础。

### 林铮 / 马库斯 / 艾琳娜（抵抗军铁三角）
- 林铮：防卫军总司令，理性、担当、沉默的爱。从「下令处决溯」到「看穿苏晓的谎却配合」。
- 马库斯：工人出身的战士，讲义气、冲动、守护。负责旧电网、柴油机、劫狱争议、炸补给站。
- 艾琳娜：战地医生，程序正义、记录与关怀。负责检疫漏洞、识别门数据流、伤员队。
- 铁三角裂痕线：第四幕 30 集（炸补给站 vs 守城）。

### 苏阳 / 小雨（亲情线）
- 苏阳：苏晓的弟弟，少年，保护姐姐与小雨。
- 小雨：孤儿，苏晓收养，儿童视角的「明天是什么」。

### 关系主引擎
- 苏晓 × 溯：信息差（人 vs 非人）→ 情感靠近（掌印→复刻恐惧→开口→命名→指尖相抵→折纸船）→ 裂痕（栽赃、出走）→ 终战（逆向入侵、溯光）。
- 苏晓 × 先知：先知以她的脸、她的笔迹、她的声音作恶——身份被窃取与夺回。
- 苏晓 × 林铮：互相看穿但互相成全；林铮为她交出指挥权。
- 苏晓 × 周衡：研发同僚 → 被其证词背刺 → 洗清后周衡自首。

## 3. 主线问题与核心戏剧问题

**核心戏剧问题**：一个把「相信」建立在对异类恐惧之上的人类文明，能否在物种边界另一边找到「人」？

**一句话卖点**：人类把最后的文明押进一个圆；一个液相体逃兵，为了用「你们的词」命名一段跨物种的感情，逆向入侵母舰自毁，留下淡银瞳孔的婴儿。

**情绪回报**：从末世生存焦虑 → 关系的克制靠近 → 身份背刺与信任危机 → 终战的牺牲与黎明——「恨了一个物种，最后爱了它的一个个体」。

## 4. 人物弧（全剧）

1. **苏晓**：证据主义者 → 为无法证明的信任担保（23 集当众划掉签字）→ 交出「选择权」（39 集送溯起飞、40 集怀抱溯光）。
2. **溯**：模仿者（复刻恐惧）→ 学习者（开口、命名）→ 选择者（出走、带回弱点、逆向入侵、自毁）→ 留下「溯光」。
3. **先知**：映照者（借脸确认存在）→ 占有者（窃取苏晓笔迹、溯的脸作恶）→ 被自己的「壳」反噬（39-40 集）。
4. **林铮**：守序军人 → 为「不能证明的对」违背命令（24 集看穿谎言却配合）→ 交出指挥权 → 黎明后放灯。
5. **周衡**：家人优先的好人 → 一步步滑向内鬼 → 34 集自首赎罪。
6. **马库斯×艾琳娜**：分歧（炸补给站 vs 守城）→ 战前婚礼和解（33 集）。

## 6. 揭示顺序（信息账本）

- 观众早于角色：先知身份（3 集伏笔 → 20 集正式现身）；周衡可疑（20 集）。
- 角色早于观众：苏晓在 14/20 集记录到门数据异常与周衡核心层权限；艾琳娜发现门在「收集」。
- 公平线索：副官半页密钥、反写符号、周衡回避妻子提问、假溯无倒影（24 集）、纸船水渍拼图（33 集）。

## 7. 结局（最终状态）

第五幕终：溯在核心舱 0.3 秒窗口击碎「心脏」、启动母舰自毁，与先知同归于尽；黑潮失去指挥退散溶解。战后清晨，苏晓在隔离室水渍里发现干透的折纸船，内侧写着「溯光」；黎光照进实验室，苏晓怀里的溯光睁开眼睛——瞳孔淡银色，伸手学着水痕的样子画了一个圆。人类在物种边界的另一侧，看见了「人」的延续。
