**音频策略：** H3 原生音效可作为"临时轨"参考，成片音轨以《03_音频与后期.md》方案替换。

## 提示词公式（H3 官方语法）

```
主体 + 一个核心动作 + 场景与空间关系 + 光线质感 + 单一运镜指令（幅度+速度） + 负向约束
```

- **运镜是句子，不是形容词**：一次只写一个运镜。支持：Push in / Pull out / Zoom in / Zoom out / Pan left / Pan right / Truck left / Truck right / Tilt up / Tilt down / Pedestal up / Pedestal down / Arc shot / Tracking shot / Static shot / POV / Roll / Shake
- **幅度与速度**：`with small amplitude`（小幅）/ `at slow speed`（慢速）/ `at fast speed`（快速）
- **负向约束写在句尾**：`no text, no watermark, no humans, no cartoon style`
- 中文提示词与英文均可，海螺对中文原生理解好；以下以**中文主推**，英文备查见括号内运镜指令

## API 调用示例（MiniMax 开放平台 video_generation）

```json
{
  "model": "MiniMax-H3",
  "prompt": "日出时分，一头深色鬃毛的成年雄狮伫立在白蚁丘顶端……[Tilt up with small amplitude at slow speed] 无文字、无水印。",
  "first_frame_image": "（keyframes 对应图的 base64 或上传后返回的 file_id）",
  "duration": 8,
  "resolution": "2K",
  "aspect_ratio": "16:9",
  "prompt_optimizer": true
}
```

**跑批要点：**
1. 全部 10 镜走 **I2V（首帧图）模式**：`first_frame_image` 传 `keyframes/` 里对应编号图，一致性最好
2. 每镜生成 2–3 条备选，优先挑动物步态/肌肉运动最自然的一条
3. H3 翻车点检查：狮子腿部关节与爪数、鬃毛穿模、角马角形变、星空段噪声闪烁
4. 若单条画面发飘，把 `prompt_optimizer` 关掉后手动精修提示词重跑
5. 素材命名 `S01_take1.mp4` …，剪辑对位见 `03_音频与后期.md`
