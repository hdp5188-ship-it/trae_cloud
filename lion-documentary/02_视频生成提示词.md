# 《草原之王》视频生成提示词（拿去 GPU 服务跑）

每个镜头提供两版提示词：
- **A 版（详细版）**：适配 Veo 3 / Sora / Kling 可灵 / 即梦等闭源大模型，或支持长 prompt 的接口
- **B 版（简洁版）**：适配 Wan2.x / CogVideoX / HunyuanVideo 等开源模型（开源模型对超长 prompt 理解差，用简短直白的描述句）

通用参数建议：
- 分辨率：1920×1080 起，画幅 16:9，帧率 24fps
- 时长：S01–S09 各 8 秒，S10 为 10 秒
- 负面提示词（所有镜头通用）：`cartoon, anime, illustration, deformed lion, extra limbs, wrong anatomy, blurry, low quality, watermark, text, subtitles, human, oversaturated`

## 使用建议（按你的 GPU 服务类型）

| 方式 | 操作 |
|---|---|
| **文生视频（T2V）** | 直接用上面的 A 版或 B 版 prompt |
| **图生视频（I2V，推荐）** | 用 `keyframes/` 目录里对应编号的关键帧作首帧图 + prompt，画面一致性会好很多 |
| **多镜头模型（Veo 3 等）** | S06 内含三段快切，若单次只支持单运镜，可拆成 3 个子片段后剪辑 |
| **时长不足 8s 的模型** | 生成后用补帧/放慢到 0.8x 延展 |
| **首尾帧能力** | S06 可用「S06a 冲刺图 → S06b 扑击图」做首尾帧，动作衔接最自然 |
